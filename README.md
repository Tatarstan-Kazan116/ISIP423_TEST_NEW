Практическая работа №7.2 — Шифр Плейфера
Выполнили: Ретюнских К.А., Сиразиев А.И. | Группа: 4ИСИП323 |
 
Описание
Шифр Плейфера — биграммный шифр, шифрующий текст парами букв.
Принцип:
1.	Из ключа строится матрица 5×5 (I=J).
2.	Текст разбивается на пары (между одинаковыми буквами вставляется X, нечётная длина дополняется X).
3.	Правила шифрования: в одной строке — сдвиг вправо, в столбце — вниз, в прямоугольнике — замена по углам.
4.	Дешифрование: сдвиг влево/вверх.

Варианты использования
Ввести ключ, ввести текст, зашифровать, расшифровать, показать матрицу, скопировать результат.
